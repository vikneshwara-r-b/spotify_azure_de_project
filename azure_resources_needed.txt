All resources have to be created in US-East Location
1. Azure Data Factory
2. ADLS Gen2 container 
3. Azure Databricks
4. Access Connector for Azure Databricks
5. Azure Managed MSSQL server and database
6. Azure Key Vault - for storing access key and MSSQL password

Perform the following role assignment in ADLS storage account from access connector
1. EventGrid Data Contributor
2. EventGrid EventSubscription Contributor
3. Storage Account Contributor
4. Storage Blob Data Contributor
5. Storage Queue Data Contributor

In databricks, I need to create the following
1. Credential
2. External storage
3. Managed tables
